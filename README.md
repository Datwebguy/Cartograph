# Cartograph

Verified executable world models for ARC-AGI-3.

A coding agent that plans only inside a world model that has exactly replayed its full history.

## Background

ARC-AGI-3 asks an agent to learn the rules of a new interactive game from observation alone and then act efficiently. Cartograph extends the open [Duck](https://github.com/Tufalabs/duck-harness) coding agent with a persistent, agent-written world model and a strict rule for when that model may be trusted. Everything runs locally with an open model on a single GPU; no external APIs are called. The method is described in [PAPER.md](PAPER.md).

## How it works

The agent maintains `world_model.py`, which defines `transition(state, action) -> next_state`.

1. After every model edit and every environment action, a verifier replays the **entire** recorded history from the initial observation through the model.
2. The model is **verified** only if every checked transition matches the observed frame cell for cell, and at least one transition was checked.
3. If verified, the model is made available to the agent's Python tool and the agent plans inside it. If not, the agent continues with the ordinary explore-and-act loop and receives the first mismatching cells.

Level changes and `RESET` are re-anchored on the observed frame and counted separately. Model code runs in a resource-limited child process with the same import allowlist as the agent's Python tool.

## Install

Cartograph is a subclass of the Duck agent, so it needs the Duck harness (Python 3.12) on the path.

```sh
git clone https://github.com/Tufalabs/duck-harness
cd duck-harness/ARC3-Inference && uv sync --locked --extra dev
cd ../.. && git clone https://github.com/Datwebguy/Cartograph
pip install -e Cartograph --no-deps
```

## Usage

Install the agent through the harness's analyzer hook:

```python
from cartograph.agent import make_analyzer_factory

solver.analyzer_factory = make_analyzer_factory(
    model=solver.model,
    timeout=solver.analyzer_timeout,
    workspace_root="cartograph_runs",  # world_model.py and verification_log.jsonl per game
)
```

Each game gets its own directory containing `world_model.py` and `verification_log.jsonl`. Summarise a run with:

```python
from cartograph.report import summarise_dir
print(summarise_dir("cartograph_runs"))
```

Run the tests (from the Duck `ARC3-Inference` environment):

```sh
PYTHONPATH=/path/to/Cartograph:/path/to/duck-harness/ARC3-Inference \
  python -m pytest /path/to/Cartograph/tests
```

The Kaggle notebook in [`notebooks/`](notebooks/) runs the agent on public games.
