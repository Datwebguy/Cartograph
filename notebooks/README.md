# Notebook

`cartograph_duck_kaggle.ipynb` runs the Cartograph agent on public ARC-AGI-3 games. It is built on the Duck notebook by Tufa Labs (credited in its first cell) and adds the Cartograph package, installs the agent through the harness's analyzer hook, limits an interactive run to the first three public games, and ends with a results table (`cartograph_results.json`).

Settings: GPU on, internet off. Everything runs locally with an open model and no external APIs.

The notebook is generated by `scripts/build_notebook.py` from the Duck template.
