# Notebooks

Both notebooks are built on the Duck notebook by Tufa Labs (credited in their first cell) and are generated by `scripts/build_notebook.py`. Each embeds the Cartograph package, installs the agent through the harness's analyzer hook, limits an interactive run to the first three public games, and ends with a results table (`cartograph_results.json`). Everything runs locally with no external APIs, with internet off.

| Notebook | What it runs | Hardware |
| --- | --- | --- |
| `cartograph_duck_kaggle.ipynb` | Cartograph with the local Qwen3.6-27B-FP8 model served by vLLM | the single large GPU the Duck setup requires |
| `cartograph_pipeline_demo.ipynb` | The same harness and agent on real public games with a fixed script in place of the language model; shows model write, exact replay, gate open and close, and logging | none |
